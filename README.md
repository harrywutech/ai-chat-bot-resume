# AI Chat Bot Resume

An AI-powered personal information and resume assistant for Harry Wu. The first milestone is a static Hello World page deployed to GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Static build

```bash
npm run build
```

The deployable site is generated in `out/`. Pushes to `main` are deployed by the GitHub Pages workflow.

Production URL: <https://harrywutech.github.io/ai-chat-bot-resume/>
